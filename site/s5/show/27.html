Introduction

This module will focus on controlling the flow of statements executed in a program using conditional structures.

A conditional structure allows the programmer to create tests that determine whether or not specific chunks of code are executed or not. These tests are composed of both relational expressions and logical operators and evaluate to either Boolean true or false.

Objectives

Upon completion of this module, you should be able to:

  • Compose and evaluate relational Boolean expressions that contain variables.
  • Compose and evaluate Boolean expressions that make use of logical operators (AND, OR, NOT)
  • Compose a conditional structure using a combination of if and else structures.

Relational Expressions

In the previous set of notes we discussed how expressions can be used to compare values using comparison operators that return Boolean values. These types of expressions are called Boolean or Relational Expressions.

Boolean expressions can contain the following common operators (and more):

Logical Operators

The Boolean logical operators AND and OR can also be used to combine relational expressions.

The AND operator is represented by two ampersands &&. The OR operator is represented by two ‘pipe’ characters ¦¦.

ExpressionValue
(true && true)true
(true && false)false
(true ¦¦ true)true
(true ¦¦ false)true
((x > 7) && (x <= 10))true only when x is 8, 9 or 10
((x < 7) ¦¦ (x >= 10))false only when x is 8 or 9

Logical Operators

The NOT operator is also available. It is represented by an exclamation mark !.

ExpressionValue
(!true)false
(!false)true
(!(x >= 0))true only when x is negative
(!(x >=0) ¦¦ (x == 5))true only when x is negative or equal to 5.

Conditionals

Conditionals allow programmers to control the flow of program execution. They let the programmer define a test (a Boolean expression) that controls whether certain chunks of code are executed or not.

For the most part, the tests used with conditionals include one or more variables.

if

The if structure is the simplest conditional structure available in Processing.

if (test)
{
   // One or more statements...
}

The test must be a Boolean expression that evaluates to either true or false. If the test evaluates to true the code inside the braces {} is executed, otherwise this code inside the braces is ignored.

The code inside a set of braces is called a block, a code block, or a block of code.

Code written inside a block should be indented by two spaces by hitting the tab key. Processing will often perform this indent for you automatically.

if (age > 10)
{
  println("You are " + age + " years old.");
  println("You're all grows up now kid.");
}

if (Flow Diagram)

if - else

We can extend an if structure using the word else.

if (test) 
{
  // Code in this block will run if the test evaluates to true.
} 
else
{
  // Code in this block will run if the test evaluates to false.
}

Remember that whitespace has no meaning in Processing, which means that some programmers format their if/else structures differently:

if (test) {
  // Code in this block will run if the test evaluates to true.
} else {
  // Code in this block will run if the test evaluates to false.
}

if - else (Flow Diagram)

if - else if

Multiple if/else structures can be linked together.

if (test1)
{
  // Code in this block executes if test1 is true.
}
else if (test2) 
{
  // This block executes if test1 is false and test2 is true.
}
else
{
  // This block executes if both test2 and test2 are false.
}

String Comparisons

When working with the data type of String we cannot use the double equals (==) syntax for comparisons. For example, the following code will not work as expected:

String dogBreed = Ibit.ask("What type of dog do you want?");

if (dogBreed == "Poodle")
{
  println("This dog does not shed very much.");
}

If we wish to test a String to see if it equal to another String we have to do the following:

String dogBreed = "Wheaten Terrier";

println(dogBreed.equals("Ghost Dog"));        // false
println(dogBreed.equals("Wheaten Terrier"));  // true

Using double equals to compare Strings in Processing works sometimes but it’s not worth the hassle. Always use .equals to compare String.
