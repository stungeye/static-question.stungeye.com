Algorithms

An algorithm is a set of instructions for solving a problem.

In other words, an algorithm is a way of capturing intelligence and sharing it with others.

A recipe is another example of an algorithm. One does not need to be an expert cook to create a meal by following a well-designed recipe.

Might a recipe written for a novice look different than one written for an experienced cook?

Seven Cell Checkers

Consider a single-player game with a playing board consists of 7 squares in a row.

The aim is swap the positions of the orange and blue pieces.

Setup

To begin, orange pieces are placed in the three leftmost squares. Blue pieces are placed in the three rightmost squares.

Game Play

Pieces can move either by sliding into an adjacent empty square, or by jumping a single adjacent piece into the empty square beyond.

Your goal is to write down step-by-step instructions for winning this game.

Your instructions should be clear enough so that someone who has never played this game can follow them without asking you any questions.

How many steps does you winning algorithm include? Can you create a version of it that only uses 15 instructions?

Computer Algorithms

Five Requirements of a Computer Algorithm

  1. The algorithm is well-ordered.
    The order in which the steps are executed matters and must be specified.
  2. The algorithm is unambiguous.
    Each step must be clearly defined such that they cannot be further simplified.
  3. All steps are computable.
    There are certain things computers cannot compute, such as division by zero.
  4. The algorithm produces a result.
    Results allow us to verify if an algorithm is correctly solving a particular problem.
  5. The algorithm will always finish in a finite amount of time.
    An algorithm that runs forever will never produce a result. See requirement #4.

Sorting

Sorting is a common problem handled by computers.

Consider how most webmail applications allow us to sort our email messages in several ways: date received, subject, sender, etc. Each time you reorder your email, your computer uses a sorting algorithm to sort them.

Since computers can compare a large number of items quickly, they can sort large collections at incredible speeds.

Selection Sort

  1. Lay out all your unsorted items in a row.
  2. Place a marker below the first item in the list.
  3. Compare the item in the marked position with all the other items to the right of this item.
  4. If you come across an item that is smaller than the marked one, swap these items.
  5. Move the marker one to the right.
  6. If the marker hasn’t yet reached the end of the list, go to step 3.

Do this a few times, each time starting with a randomized list.

How many comparisons do you need to make to sort the list each time?

Efficiency of Algorithms

For any given problem, it is possible that there is more than one algorithm that represents a correct solution.

Two important considerations for judging the efficiency an algorithm are:

  • Time Efficiency: How long it will take to solve the problem?
  • Space Efficiency: How much memory will it use while solving the problem?
