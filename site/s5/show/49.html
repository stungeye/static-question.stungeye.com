What is Scratch?

Scratch is a programming language and online community where you can create your own interactive stories, games, and animations – and share your creations with others around the world.

In the process of designing and programming Scratch projects, you will learn to think creatively and reason systematically.

The programmings skills you develop with Scratch will help you better understand the Java coding we do in the second half of this course.

Sprites and the Stage

Each object in Scratch is called a sprite.

The cat you see in when you start Scratch is an example of a sprite.

Sprites can be controlled with code and can have multiple costumes.

Every Scratch program also has a stage.

The stage can also have associated code and multiple backdrops.

Statements

In programming, a statement is a directive that tells the computer to do something. You can think of it as a command or an instruction.

In Scratch, any block whose label reads like a command is a statement.

Scratch statements can be connected together. Blocks that are connected will execute one at a time from top to bottom.

You’ll know if you can snap two blocks together if they fit together like a puzzle piece.

Commenting Your Code

Comments are the parts of our code that are ignored by the computer but are important for people.

Comments let us write notes to ourselves and to any others who may read our code. These notes allow us to document our design decisions and to explain complex portions of our code.

In Scratch we can attach comments directly to the blocks they describe by right-clicking a block and selecting “add comment”.

We can also add comments that are not attached to specific blocks by right-clicking the background of the coding area and selecting “add comment”.

Online vs Offline Scratch

Scratch is available on the web but it can also be installed as an offline application.

The web version is Scratch is available at scratch.mit.edu.

The offline version of Scratch can be downloaded at scratch.mit.edu/scratch2download/.

Differences between the online and offline versions.

Online Scratch:

  • No installation required.
  • Run using a web browser.
  • Programs are saved to the Scratch website.

Offline Scratch:

  • Must be first downloaded and installed to your computer.
  • Run as an application on your computer.
  • Programs are saved as files on your computer.

Submitting Scratch Assignments

Your Scratch assignments will be submitted digitally using the Learn dropbox. For each assignment you will be submitting one or more .sb2 files.

If you have been working with the online Scratch you will need to download your code to your computer before you submit it:

  • Click on the File Menu.
  • Select “Download to your computer”.
  • Save the .sb2 file to a know location on your hard-drive.

If you have been working with the offline Scratch program you will have been saving your work to your hard-drive in this format already.
