Introduction

When creating or using markup it is important to ensure that our documents are valid.

With HTML we use the W3C validator to validate our markup. With XML we can validate our markup using an XML Schema Definition or XSD.

An XSD describes the structure of a specific XML document along with the data types of the document elements.
