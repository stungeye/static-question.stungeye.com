Competency Based Learning in ACE Courses

Here’s what I’ve tried…

  • Variable pace (supported by videos).
  • Project-based, personalized learning.
  • Ability to self-assess and peer-assess to gauge progress.
  • Meaningful in-person assessment feedback.
  • Mastery before advancement.

Pros and Cons

PROS

  • In Person Feedback / Code Reviews
  • Project Management Skills
  • Customized Learning Leading to Mastery
  • Plagiarism Reduction
  • Marking Workload

CONS

  • Marking / Feedback Takes Over Class Time
  • In-Person Critique Can Be Difficult / Awkward
  • Debug Assistance on One-of-a-Kind Projects is Tricky
  • Lots of Face-2-Face Time is Draining
